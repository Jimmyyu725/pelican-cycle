# 鹈鹕邮局 · 海风有信

一个可离线打开的单文件 HTML 三维小世界。双击 `index.html` 即可进入；图形库、样式、模型和交互均包含在文件内，无需安装或联网。

## 世界观

鸥湾是一座靠来信计时的海岛，没有汽车，也没有催件电话。鹈鹕阿鹈沿海岸环线为邮局、松风坡和灯塔送信。薄荷绿单车、珊瑚色灯塔、松林和暖沙色道路组成统一的微缩海港。

## 建模与交互

- 鹈鹕：白色躯体、弯曲长颈、定制长喙和下垂喉囊、分层飞羽、邮差帽和围巾。
- 自行车：三角车架、轮胎与轮辐、相反相位的曲柄、随踏板移动的双腿与蹼足、后置邮包。
- 环境：海面、远岛、灯塔、邮局、松树、码头、小船、花草、海鸟和动态阴影。
- 拖动旋转；滚轮或双指缩放；方向键旋转；空格暂停。
- 底栏可调速、响铃、切换晨光/落日、重置视角；右上角可看角色近景与小岛手记。
- 系统开启减少动态效果时，默认暂停骑行。

## 验证

浏览器测试使用 Playwright。测试脚本优先使用当前环境的 Playwright；本机也可使用 Codex 附带的依赖。

```sh
node verify.cjs baseline
node verify.cjs modified
```

`VERIFICATION.txt` 保存输入、命令、实际输出、退出码、原始文件哈希和回退验证。
`ROLLBACK.sh` 默认恢复项目内的 `index.html`，执行前先另存当前文件，也支持传入单独的测试副本路径。已验证的回退仅作用于测试副本，交付页面仍保留完整场景。
